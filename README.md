# Expense Tracker (Python)

A command-line expense tracker built with Python that allows users to manage daily expenses using CSV storage.

## Features

- Add expenses
- Store expenses in CSV
- Load saved expenses
- Automatic expense IDs
- Input validation
- Modular project structure

## Tech Stack

- Python 3.12
- Dataclasses
- CSV
- Pathlib
- Git & GitHub
